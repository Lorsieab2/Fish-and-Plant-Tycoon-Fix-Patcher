FISH & PLANT TYCOON FIX PATCHER

🪴 Created with Codex AI. Made with love by Lorsieab2 :) 🐟

0. Use the free Windows downloads from LDW's own site, https://ldw.com.
   Those are the only supported copies. Builds from anywhere else are
   refused, not patched.
1. Close Fish Tycoon, Plant Tycoon, and any trainer before patching.
2. Double-click "Launch Fish and Plant Tycoon Fix Patcher.bat".
3. Click "Find Both in Parent Folder..." and choose the folder your game
   folders sit in. Use "Find Fish Tycoon..." or "Find Plant Tycoon..." for
   one game. You can also fill in the folders yourself.
4. Choose "One Game" or "Both Games".
5. Leave the fixes you want checked. "Defaults", "Enable All", and
   "Disable All" set the whole list for that game at once.
6. Use Dry Run to validate without writing files.
7. Choose where the modified game folders should be saved.
8. Click Create Modded Copy or Patch Both.

The patcher creates only "Fish Tycoon - Modded" and/or
"Plant Tycoon - Modded" beneath the chosen location. Their executables use
those exact names plus ".exe", keeping their saves in the matching - Modded
save locations. The patcher remembers the chosen paths. The blue underlined
paths open those folders in File Explorer.

The original game folders are never replaced. Exact unsupported or already
modified EXEs are refused. The package contains no game executable or game
asset.

To restore the original EXE inside a modded folder, choose One Game, select its
timestamped backup folder and modded output folder, then click
"Restore Output EXE from Backup".

Each option in the patcher describes exactly what it changes and where.

Fish Tycoon options:
- Crimson Comet 20% curing fix
- Unknown Chemical: 3 uses
- Universal supply slots 2-4
- Golden Seahorse repurchase (optional, off by default)

Plant Tycoon option:
- No old-age plant deaths
